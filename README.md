# Tayo Opeyemi — Lead Systems Architect Portfolio

Scaffolded Next.js 15 app with Tailwind 4, Framer Motion, and React Three Fiber.

Install:

```bash
npm install
npm run dev
```

Notes:
- Replace `public/logo-full.png` and `public/hero-portrait.png` with real assets.
- Set environment variables from `.env.example`.
- The `ArchitectureVisualizer` is a client component and loaded dynamically with SSR disabled.
